# D2C component workshop

Use this Storybook to build, inspect, and share React components implemented from approved Figma nodes.

## Add a component

1. Share the exact Figma component or variant-set URL.
2. Collect its design context, variable definitions, and screenshot before coding.
3. Implement the public component and add its export to `src/components/index.ts`.
4. Create stories whose first named export is `Default` and whose render functions pass all args to the component.
5. Verify the finished stories, controls, states, accessibility, and console in the browser.

The complete implementation contract is stored in `AGENTS.md` at the repository root.
